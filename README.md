Behavioral Health Optimization System

A smart behavioral intelligence system that tracks user habits, detects patterns, and provides personalized mental health insights using AI.
Features:
Mood tracking
Habit monitoring
AI-based recommendations
Behavioral pattern detection
Problem It Solves:
Most health apps only track data but don’t help users change behavior. This system focuses on behavioral improvement through insights and interventions.
Tools used:
HTML
CSS
JavaScript
Gemini API
LocalStorage
